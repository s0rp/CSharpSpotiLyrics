# Security Policy

## Supported Versions

Active security updates and bug fixes are applied exclusively to the latest stable release (v2.x). Legacy versions (v1.x) are no longer supported due to fundamental changes in the authentication and API architecture (specifically, the complete removal of Playwright in favor of direct HTTP/Regex parsing).

| Version | Supported          | Notes                                     |
| ------- | ------------------ | ----------------------------------------- |
| v2.0.1 & v2.0.2    | :white_check_mark: | Currently supported stable release.      |
| v2.0.0    | :x:                | Deprecated. No longer supported.          |
| v1.x    | :x:                | Deprecated. No longer supported.          |
| < v1.0  | :x:                | Deprecated. No longer supported.          |
